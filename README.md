# Physics Templates for Python for labs and computation

quick overview

## Dependencies
  - Numpy
  - Matplotlib
  - Pandas

### Numpy:
  For fast c optimised code for fast computation of arrays and larger datasets.
### Pandas:
  Similar to excel in functionality the formatting cleaning and tabling of raw and processed data which works well in conjunction with numpy.
### Matplotlib:
  For Reports and visualisation of collected and computed data.
